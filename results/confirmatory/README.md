# Confirmatory results

I report the completed confirmatory analysis in this directory, together with the aggregate records and numerical inputs needed for reanalysis.

- `summary.json` is the complete machine-readable analysis report generated by `python -m experiments.statistics`.
- `official_runs.jsonl` exports the 133 successful aggregate records in frozen manifest order; workstation-specific harness paths are normalized.
- `RESULTS.md` presents the main result and its interpretation boundary for human readers.
- `figures/` is generated by `python -m experiments.visualize`.
- `evidence/` contains text-free aligned item outcomes and provenance for `python -m experiments.evidence_bundle verify`.

The raw `lm-evaluation-harness` outputs and per-sample logs are stored locally under `results/lm_eval/`. They are not tracked because the directory is about 1.7 GB. The tracked summary keeps the primary statistic, bootstrap intervals, McNemar appendix, BI overlap metadata, canonical-versus-legacy BI rank correlations, and SHA-256 hashes of every input record and sample log. Since the September 24 review, the compact evidence bundle enables reanalysis from a fresh clone without raw texts, model weights, or a GPU. It contains document identities, per-document likelihood/word counts, and per-question correctness, not prompts or model responses. It does not rerun model inference.

Primary result: BI ranked better than all twenty sampled random permutations on the `k=4` WikiText endpoint across the three Qwen2.5-7B checkpoints. The one-sided Monte Carlo rank p-value is `1/21 = 0.047619` under the layer-label invariance null stated in [RESULTS.md](RESULTS.md).

The edge-free secondary diagnostic includes eight controls and gives a conditional rank p-value of `1/9 = 0.111111`. I restrict the interpretation to the specified permutation comparison; the analysis does not establish superiority across other pruning settings.
