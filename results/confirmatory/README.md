# Confirmatory results

This directory contains the tracked output of the completed confirmatory experiment.

- `summary.json` is the complete machine-readable analysis report generated by `python -m experiments.statistics`.
- `official_runs.jsonl` exports the 133 successful aggregate records in frozen manifest order; workstation-specific harness paths are normalized.
- `RESULTS.md` presents the main result and its interpretation boundary for human readers.
- `figures/` is generated by `python -m experiments.visualize`.

The raw `lm-evaluation-harness` outputs and per-sample logs are stored locally under `results/lm_eval/`. They are not tracked because the directory is about 1.7 GB. The tracked summary keeps the primary statistic, bootstrap intervals, McNemar appendix, BI overlap metadata, canonical-versus-legacy BI rank correlations, and SHA-256 hashes of every input record and sample log. Recomputing sample-level statistics from a fresh clone therefore requires a separately supplied, hash-matching copy of those logs.

Primary result: BI ranked better than all twenty frozen conditional random permutations on the `k=4` WikiText endpoint across the three Qwen2.5-7B checkpoints. The exact one-sided p-value is `1/21 = 0.047619`.

Important boundary: the edge-free secondary diagnostic has only eight controls, so its exact p-value is `1/9 = 0.111111`. The result supports the fixed conditional permutation claim, not a broad claim that BI always beats random layer pruning.
